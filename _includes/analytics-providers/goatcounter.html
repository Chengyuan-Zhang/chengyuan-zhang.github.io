{% comment %} GoatCounter: cookie-free and stores no personal data, so no consent banner is required. Set analytics.provider to "goatcounter" and analytics.goatcounter.code to the site code in _config.yml. Beyond page views this records clicks on PDF and .bib links as events, so CV, poster and slide downloads show up separately. It also records links to research summaries, GitHub repositories, the traffic simulator, and the email contact. Event paths omit query strings and email addresses. no_session is set so repeat clicks by the same visitor are all counted, per https://www.goatcounter.com/help/js. {% endcomment %} {% if site.analytics.goatcounter.code %} {% endif %}
